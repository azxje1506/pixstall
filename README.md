# Pixstall

Store-ready App Store & Google Play screenshots — plus the Play feature graphic — built in your browser.

- 5 layouts, thin device frames (iPhone / Pixel / frameless, 4 colors), real **3D tilt** (rotate X/Y/Z + thickness)
- Backgrounds: color, gradient, seamless **panorama**, blurred screenshot
- Every store size + **custom sizes** (with store-rule warnings)
- Multi-language captions, store rule checker
- Export ZIP: exact pixel sizes, PNG **without alpha** (RGB) or JPG — rendered locally, nothing uploaded

## Dev
```bash
npm i
npm run dev
```
Stack: Next.js · React · lucide-react · html-to-image · fast-png · JSZip
